# 📊 Análise Estratégica de Vendas: BMW Global (2018-2025)

Este projeto apresenta um diagnóstico completo da performance comercial da BMW, utilizando ciência de dados para extrair insights sobre faturamento, transição energética e comportamento de mercado.

## 🚀 Tecnologias Utilizadas
* **Linguagem:** Python 3.13
* **Ambiente:** VS Code / Jupyter Notebook
* **Bibliotecas:** Pandas (Tratamento), Plotly (Visualização Dinâmica), Kaleido (Exportação)
* **Design Final:** Canva (Relatório Executivo)

## 💡 Principais Análises
* **Evolução Regional:** Comparativo de faturamento entre Europa, China e USA.
* **Transição Elétrica:** Crescimento do Market Share de veículos BEV.
* **Elasticidade de Preço:** Relação entre Ticket Médio e Volume de Vendas.

## ⚠️ Aviso Legal e Ética
Este é um projeto de **Portfólio Fictício**. 
* Os dados foram obtidos publicamente na plataforma **Kaggle**.
* Informações reais de empresas privadas são confidenciais; este estudo simula um cenário real para demonstração de competência técnica.
